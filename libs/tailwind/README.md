# @lumina/tailwind

Tailwind **preset (v3)** and **theme (v4)** generated from the Lumina UI design
tokens. Every value is a live `var(--lui-…)` reference — the same custom property
the Angular components consume — so Tailwind utilities respect the active
`data-theme` (light / dark / high-contrast) and the runtime accent exactly like
the rest of the system.

> Tailwind-friendly, never Tailwind-required. The tokens ship as plain CSS
> variables; this package is only for teams who _want_ Tailwind.

Both files are generated by the token build (`nx run tokens:tokens`) — do not
edit them by hand.

## Tailwind v3 — preset

```js
// tailwind.config.js
module.exports = {
  presets: [require('@lumina/tailwind')],
};
```

Then use token-backed utilities:

```html
<button class="bg-accent text-accent-fg rounded-md px-4 py-2 shadow-md">Save</button>
<div class="bg-surface-canvas text-fg border border-strong">…</div>
```

## Tailwind v4 — `@theme`

```css
@import 'tailwindcss';
@import '@lumina/tailwind/theme.css';
```

The same utilities resolve through Tailwind v4's theme namespaces
(`--color-*`, `--radius-*`, `--shadow-*`, `--spacing-*`, `--text-*`, …).

## What's mapped

| Tokens              | Tailwind (v3 key / v4 namespace)                     |
| ------------------- | ---------------------------------------------------- |
| `color.accent.*`    | `colors.accent` / `--color-accent*` (`bg-accent`)    |
| `color.bg.*`        | `colors.surface` / `--color-surface-*`               |
| `color.fg.*`        | `colors.fg` / `--color-fg-*` (`text-fg`)             |
| `color.border.*`    | `colors.border` / `--color-border*`                  |
| status + palettes   | `colors.{success,warning,danger,info,neutral,…}`     |
| `space.*`           | `spacing` / `--spacing-*`                            |
| `radius.*`          | `borderRadius` / `--radius-*`                        |
| `shadow.*`          | `boxShadow` / `--shadow-*`                           |
| `font.*`            | `fontFamily` / `fontSize` / `fontWeight` / `leading` |
| `duration`,`easing` | `transition*` / `--ease-*`                           |

`default` maps to Tailwind's `DEFAULT`, so `bg-accent` and `text-fg` work.
Breakpoints are intentionally omitted — media queries cannot read custom
properties, and breakpoints are not themed.

## Guarantee

A contract test (`libs/tokens/src/lib/tailwind-contract.spec.ts`) verifies that
every `var(--lui-…)` this package references is actually defined by the CSS token
build — so a Tailwind app and an Angular app render from identical values.
